# Blender MCP Pro v4.9.0-alpha.2

The [published prerelease](https://github.com/camilin7483/blender-mcp/releases/tag/v4.9.0-alpha.2)
is built from commit `31b6f2e1c47768fae517c69f1230b1139d59dc2b`.
It preserves the independent audit fixes and reduces character rig build time
by writing planar UVs in bulk and binding Blender's automatic weights on the
base cage before restoring the subdivision modifier.

See the [twelve character tools and rig workflow](../workflows.md#create-and-verify-a-character-rig)
and the [full tool reference](../tools.md) for inputs and examples.

## Verification

- 34 host tests passed. The stdio registry exposes 313 unique tool names with
  handler and schema parity.
- Blender 4.5.4 and 5.2.4 passed the real headless and GUI tests on Linux. All 12
  character tools passed the authenticated socket test.
- The 46-task benchmark passed in each of three runs on both Blender versions.
- Seven jobs passed in the [release commit's GitHub Actions run](https://github.com/camilin7483/blender-mcp/actions/runs/44691708164).
- The normalized extension ZIP was identical when built with both Linux
  Blender versions. SHA-256:
  `c8adc46008380c3fc9c88128ba24f33fc2ba15dcd99912e1e24b43b7c6e47acf`.

Native Windows/macOS GUI and rendering coverage remains open. See the
[compatibility matrix](../compatibility.md) and [stable gate](../release-checklist.md).
