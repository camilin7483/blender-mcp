# Release v4.9.0-alpha.1

Date: 2026-11-20

Commit: `5e76912cfe292ab5cfd7bfc3a0e2b1e5a365c775`

Tools: **313**

## Scope

- High-detail procedural character base: anatomical head, layered eyes, skin
  shader with subsurface/pores, typed dental arch, unified body and garment
  shell.
- Curve-based hair, eyebrow and eyelash grooms.
- 39-bone body rig with automatic weights and a character studio.
- Character quality gate that reports structural scope and explicitly refuses
  AAA certification.
- World, material library, animation FX, QA, physics and weather packs from
  the v4.7-v4.8 tranches.

## Character quality statement

`character_quality_report` returns:

- `tier`: `procedural_high_detail`
- `aaa_certified`: `false`
- `production_ready_scope`: `structural_base_only`
- `missing_for_aaa`: scanned/artist primary forms, UDIM texture sets,
  pore-level maps, guide-based dynamic groom, facial FACS rig and human art
  review.

This release does **not** claim photoreal or AAA character certification.
