# Legacy single-file add-on

This is the original v3 `blender_mcp.py` add-on, preserved for compatibility.
It is not the Pro bridge. Install it in Blender only if you need the legacy
surface; the Pro add-on lives in `pro/blender_mcp.py`.

The file moved out of the repository root so it no longer shadows the
`src/blender_mcp` Python package used by the bridge and tests.
